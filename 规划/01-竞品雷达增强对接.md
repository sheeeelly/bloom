---

## 2. 背景与现状 As-Is

- BD 五站+Azazie 脚本可跑：上新/下架/排名/属性/周报。  
- 产物偏 Excel/Sheets/Markdown，与选款/中枢未 API 化打通。  
- 痛点：运营手工摘录；中枢无法稳定订阅周次指标。

## 3. 目标与非目标

**目标**：提供稳定、带 data_week 的趋势/变更/样本商品接口或同步表；标注数据质量。  
**非目标**：本期扩全品类爬虫、重做前端 Dashboard（可并行原 PRD）。

## 4. 用户与场景

| 角色 | 场景 |
|------|------|
| 提案中枢 | 按 BD+周次拉 Top 色/领型/上新样本 |
| 品类运营 | 从竞品 SKC 点「生成提案」跳中枢 |

## 5. 范围与优先级

| 优先级 | 需求 |
|--------|------|
| P0 | 趋势汇总 API/表：top_colors, top_attrs, new/delisted counts |
| P0 | 变更明细只读：change_type, skc, url, image |
| P0 | data_quality：部分站点失败可见 |
| P1 | 商品详情弹窗字段与中枢预填一键带入 |
| P2 | 多品类配置扩展 |

## 6. 业务流程 To-Be

```text
定时/手动抓取 → 标准化入库 → 基线对比 → 聚合趋势指标 → 中枢查询
```

## 7. 功能需求列表

| ID | 需求 | 验收要点 | 主笔 |
|----|------|----------|------|
| C-01 | GET trends | 指定 category_line/week 返回聚合 | T |
| C-02 | GET changes | 分页上新/下架 | T |
| C-03 | 质量头 | partial_success 站点列表 | T |
| C-04 | 字段含归一 attr | 使用 md_attribute_dict | T |

## 8. 数据口径与字段

**输入**：竞品站点页面/API。  
**输出**：data_week, site_code, skc_key, rank, rank_change, prices, normalized attrs, change_type, product_url, image_url。  
**口径**：SKC=`product:::color`；排名涨跌=上周−本周；首次仅基线。

## 9. 系统边界与对接

| 上下游 | 接口/事件 | 频率 | 失败降级 | 责任人 |
|--------|-----------|------|----------|--------|
| → 04 | trends/changes | 周/按需 | 中枢标黄 | T |
| → 03 | 属性分布可选 | 周 | 忽略 | T |

## 10. 非功能

查询 P95 < 3s；抓取失败不写坏基线；AI 周报不阻塞指标 API。

## 11. 验收标准与指标

中枢联调可读最近两周 BD 趋势；与现有 Excel 抽样一致率抽检达标。

## 12. 开放问题

API 优先还是数仓表优先；AT 等业务线是否复用同一站点配置。
