## 1. 口径总原则

| 层级 | 主键 | 用途 |
|------|------|------|
| 上游机会 | `data_week` + `feature_set` + `signal_refs` | 论证「做什么」 |
| 中游流程 | `proposal_id` | 审核立项打板 |
| 下游商品 | `goods_id` | 修图/上架/ERP/售卖 |
| 组织权限 | `category_line` | JP/BD/AT/WD/PROM |

流水数据可变；**主数据**必须权威单一、有维护人。

## 2. 主数据（MDM）清单

### 2.1 md_category（品类）

| 字段 | 说明 |
|------|------|
| category_line | 选款业务线枚举，不擅自扩展 |
| category_code | 全局编码，如 bridesmaid_dresses |
| category_name | 展示名 |
| selection_category_name | 选款下拉显示名（映射） |
| competitor_category_id | 竞品侧品类 ID（可空） |
| enabled | 是否启用 |

**权威源建议**：新建统一品类字典；选款与竞品均映射到此，不互为权威。

### 2.2 md_attribute_dict（特征）

| 字段 | 说明 |
|------|------|
| attribute_key | color_family / fabric / neckline / silhouette / length / price_band … |
| raw_value | 原始写法 |
| normalized_value | 归一值 |
| locale | en/zh |
| aliases | 别名列表 |
| status | active/deprecated |

**权威源建议**：商品+数据共建；竞品解析与销量模型只许读归一值。

### 2.3 md_competitor_site（竞品站点）

| 字段 | 说明 |
|------|------|
| site_code | bg/ss/cl/bb/hm/az … |
| site_name / brand_name | 展示 |
| base_url / currency / country | 站点属性 |
| enabled | 开关 |

**权威源**：竞品模块 competitor_sites。

### 2.4 md_goods（商品身份）

| 字段 | 说明 |
|------|------|
| goods_id | 内部商品 ID |
| spu / sku | ERP/前台 SKU |
| category_line / category_code | 冗余便于过滤 |
| status | 开发中/已上架/下架 |
| proposal_id | 来源提案（可空，非系统款） |

**权威源**：**待拍板**（ERP vs PIM vs 选款回写）。在拍板前，选款 `goods_id` 视为流程侧登记值，与 ERP 映射表单独维护。

### 2.5 关系钉

`proposal_id` ↔ `goods_id`（1 提案完成态对应 1 主 goods；多色扩展规则 P2 再定）。

## 3. 骨干流转字段

| 字段 | 产生环节 | 消费环节 | 说明 |
|------|----------|----------|------|
| category_line / category_code | 创建机会/提案 | 全链路 | 权限与统计维 |
| feature_set | 01/03 解析与建模 | 04 设计点、03 打分 | JSON |
| signal_refs | 04 | 05 展示、09 归因 | 溯源数组 |
| hub_draft_id | 04 | 05 幂等 | 中枢草案 ID |
| generation_source | 05 | 09 | manual / system_hub |
| proposal_id | 05 创建 | 05–09 | 中游主键 |
| batch_type | 05 终审 | 06 | 打版类型 |
| goods_id | 06 完成 | 07/08/09 | 下游主键 |
| sales_metrics | 08 | 09/03 | 销量包 |
| listing_status | 07 | 09 | 上架状态 |

## 4. 分板块 Input / Output

| 板块 | 数据来源 | 核心输出 | 关键字段 |
|------|----------|----------|----------|
| 01 竞品 | 站点抓取 | 快照/变更/趋势/周报 | data_week, skc_key, rank, price, attrs, change_type |
| 02 舆情 | 工单+评论 | 避雷包/L1 Top | pdl1, pdl2, rating, sku? |
| 03 分析 | 订单+属性+退货 | success_score, pred_sales | feature_set, slow_risk |
| 04 中枢 | 01+02+03 | 选款对齐草案 | source_*, images, fabric, price, design_points, signal_refs |
| 05 选款 | 中枢/人工 | 审核流、版单 | proposal_id, status, batch_type, goods_id |
| 06 排期 | 立项提案 | 打板完成 | schedule_week, pattern_status, goods_id |
| 07 修图上架 | goods_id+素材 | 上架完成 | listing_status, go_live_at |
| 08 ERP | goods_id | 销量退货库存 | qty, gmv, return_rate |
| 09 回收 | 提案↔goods↔销售 | 命中率/绩效 | generation_source, sales_metrics |

## 6. 竞品侧关键口径（只读摘要）

| 口径 | 定义 |
|------|------|
| SKC | product_key ::: color_name |
| 排名涨跌 | 上周排序 − 本周排序；新品空 |
| 上新类型 | 新 SKC / 新颜色 / 下架后又上新 |
| 首次抓取 | 只建基线，不全量当上新 |
| data_week | ISO 周 |
