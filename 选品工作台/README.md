# 选品智能化工作台 · Demo

静态原型，UI 对齐 **内部数据选品建议引擎（Merchandising Intelligence）**：深色侧栏 + 白底主区 + 筛选卡 + 高密度数据表。

## 打开方式

```bash
cd 选品工作台
python -m http.server 5173
```

访问：<http://localhost:5173>（或直接打开 `index.html`）

## 页面与能力映射

| 页面 | 对应能力 |
|------|----------|
| 机会总览 | KPI 条 · 机会矩阵表 · 社媒/避雷侧栏 |
| 机会池 | 搜索筛选 · 四维分 · 象限/优先级/状态 · 三信号融合 |
| 竞品上新 | 站点/属性聚合 · 上新明细表 |
| AZ vs Gap | Gap 矩阵 · 缺口分组 |
| 避雷榜 | PDL 表 · 高风险候选联动 |
| 一键出提案 | 选款字段预填 · 同步草稿（模拟） |

## UI 组件

- **象限标签**：重点机会 / 成熟优势 / 风险冗余 / 持续观察
- **优先级**：P0 / P1 / P2
- **适配度条**：0–100 分色
- **状态**：可推进 / 观察中 / 已阻断 / 待扩产

## 技术说明

- 纯 HTML + CSS + JS，无构建依赖
- Mock 数据在 `app.js` → 后续接 `selection_signal_records` API
