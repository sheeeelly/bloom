# 2026-W25 竞品商品趋势周报

## 执行摘要
- 本周最强动作来自 **Birdy Grey**：商品体量最大（8765），且 **上新 519、排名上升 3769**，说明其仍在高频扩充款色并推动整体榜单活跃度。
- 颜色上，多个站点共同指向 **Black、棕调/咖调、黄调、蓝调、绿色系**：如 Babyboo 的 Blush / Lemon / Plum Brown，Birdy Grey 的 Espresso / Sage，Club L 的 Powder Blue / Lemon，Six Stories 的 Chocolate。
- 款式上，竞品持续集中在 **Maxi 长裙、缎面、非对称/挂脖/单肩领型、垂坠与围巾感细节**；设计元素统计也验证了 satin、matte satin、chiffon、scarf、draped 的高频。
- 周对周看，**Club L London** 虽然整体下降商品更多，但新上架直接冲到前排，说明其在用新品测试高热视觉款；**Six Stories** 则明显把流量集中到 Chocolate 色的新款 bridesmaid dress。
- 对 Azazie 来说，可重点参考：**用稳定基础色 + 季节感浅亮色做双线布局**，并在列表页强化 “缎面长裙 / 非对称领口 / 围巾垂坠细节 / 婚礼宾客与伴娘场景” 的组合表达。

## 三、颜色趋势
**本周颜色趋势可归纳为 4 个方向：**

1. **基础深色持续稳盘**
   - Black 在 5 个站点都进入 Top 颜色。
   - Birdy Grey 的 Espresso、Six Stories 的 Chocolate、Babyboo 的 Plum Brown 说明 **棕调深色** 正在成为黑色之外的重要礼服色。

2. **绿色系仍有稳定需求**
   - Birdy Grey 的 Sage、Emerald 仍在高位。
   - Six Stories 有 Sage、Moss Green。
   - Club L London 的 Light Green 涨幅明显。
   - 说明绿色系仍是婚礼/伴娘场景的重要色带。

3. **浅亮色承担吸睛角色**
   - Club L London 的 Powder Blue 占据 Top 商品前列。
   - Hello Molly 的 Light Blue 包揽前四。
   - Babyboo 有 Lemon，Club L 也有 Lemon 强势上升。
   - 说明 **浅蓝、浅黄** 更适合做首页视觉和季节性引流色。

4. **粉调与柔和中性色作为补充**
   - Babyboo 的 Blush 上升明显。
   - Birdy Grey 上新有 Pale Blush、Apricot。
   - Six Stories 的 Champagne、Oyster 仍在主色中。
   - 这类颜色更适合婚礼柔美场景，但本周爆发力不如深色和浅蓝/黄。

## 四、设计趋势
结合各站 Top 商品与设计元素统计，本周设计趋势如下：

- **面料**
  - satin 4878、matte satin 4338、chiffon 4017，为绝对主流。
  - 各站 Top 商品也大量出现 Satin / Matte Satin。
  - 说明礼服市场仍以 **缎面光泽感 + 轻盈垂感** 为核心。

- **领型**
  - v-neck 1804、cowl neck 1802、strapless 1456、halter 908、asymmetric 854。
  - 站点表现上，Club L、Hello Molly、Six Stories 都在强化 **asymmetric / one shoulder / halter / cowl**。
  - **off shoulder** 统计仅 4，说明不是当前主流方向。

- **裙型**
  - a-line 2336、column 1162、maxi 1063、mermaid 911。
  - 实际榜单里最强的是 **Maxi 长裙**，尤其适合婚礼宾客、伴娘、正式场景。

- **开叉**
  - leg slit / split / high slit 合计较高，说明礼服仍强调修长与露肤平衡。
  - 虽然本周 Top 商品名称中未大量直接体现，但仍是常见卖点。

- **工艺细节**
  - scarf 994、draped 891、corset 797、bow 672、pleated 640。
  - Club L London 多次出现 **scarf / draped / ruched**；
  - Six Stories 有 **cape** 款进入前列；
  - 说明 **围巾感、垂坠感、结构塑形** 是当前高频细节。

## 五、平台共性
- **Maxi 长裙仍是最稳定的核心品类**，尤其在 Babyboo、Club L、Hello Molly 表现最明显。
- **同一版型做多颜色，或同一颜色做多领型**，是多个竞品共同采用的效率打法。
- **深色系负责成交稳定性，浅亮色负责视觉拉新**，两者并行而非替代。
- **缎面 + 非对称领口 + 垂坠/围巾细节**，是本周最值得关注的组合。
- 婚礼/伴娘场景中，竞品越来越强调 **系列感陈列**，而不是单款孤立展示。

## 六、对 Azazie 的建议

### 选品建议
1. **强化 Maxi 长裙主轴**
   - 竞品 Top 商品高度集中在 Maxi Dress，Azazie 可继续把长裙作为礼服/伴娘核心盘。
2. **做“同色多版型”系列**
   - 参考 Birdy Grey、Six Stories：同一颜色下覆盖 cowl neck、halter、asymmetric、square neck、one shoulder。
3. **做“同版多颜色”扩色策略**
   - 参考 Hello Molly、Babyboo：成熟版型可快速扩到深色、绿色、浅蓝、浅黄。
4. **优先布局缎面与轻礼服感面料**
   - satin、matte satin、chiffon 仍是主流，适合继续作为重点开发方向。
5. **增加围巾垂坠感细节款**
   - scarf、draped 在统计和 Club L 商品中都很强，适合做首页主推款和活动款。

### 列表页 / 推荐位建议
- 首页/列表页可按 **“深色稳定成交” + “浅亮色吸睛引流”** 双区陈列。
- 推荐位优先组合：
  - **缎面 Maxi**
  - **Asymmetric / One Shoulder / Halter**
  - **Scarf / Draped 细节**
- 可设置专题模块：
  - “婚礼宾客浅蓝精选”
  - “伴娘深色系精选”
  - “单肩/不对称领口系列”
- 对成熟爆款，建议在列表页直接展示 **多色卡**，强化“同款多色可选”的购买心智。

### 营销素材建议
- 主视觉可参考竞品高频表达：**浅蓝或浅黄背景下的缎面长裙**，突出流动感和光泽感。
- 视频/短图重点展示：
  - 走动时的裙摆垂坠
  - 单肩/挂脖/不对称领口上身效果
  - scarf、draped、cape 等动态细节
- 婚礼场景素材建议增加：
  - 同色不同版型多人同框
  - 同版不同颜色并排展示
  - 深色系正式场景 vs 浅亮色户外婚礼场景

### 颜色建议
以下颜色名均来自可选颜色参考，建议 Azazie 优先关注：

1. **Black**
   - 五站共同高频出现，是最稳定的基础成交色，适合做全年核心色。
2. **Sage**
   - Birdy Grey、Six Stories 等站点持续出现，绿色系在婚礼/伴娘场景仍有稳定需求。
3. **Navy**
   - Babyboo、Birdy Grey 均有覆盖，适合作为 Black 之外更柔和的深色替代。
4. **Black + Sage**
   - 适合做“基础色 + 婚礼自然系”双主推组合，兼顾正式感与场景感。
5. **Black + Navy**
   - 适合用于更成熟、晚宴感、正式婚礼宾客场景。
6. **Sage + Navy**
   - 可用于伴娘系列扩色，形成冷静、统一、易搭配的色盘。
7. **Black + Sage + Navy**
   - 建议作为 Azazie 当前礼服/伴娘核心三色带，既符合竞品共性，也便于做系列化陈列。
