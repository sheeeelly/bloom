- 主推面料仍应围绕 **matte satin / satin / chiffon**

## 五、平台共性

多个网站共同出现的趋势主要有以下几点：

### 1. 长款礼服是绝对主场
Babyboo、Hello Molly、Club L London、Six Stories 的 Top 商品都高度集中在 **Maxi Dress**。  
说明当前竞品在重点推：
- 婚礼宾客
- 伴娘
- 正式场合
- 晚宴 / 派对礼服

### 2. 缎面是最强面料方向
无论是 Birdy Grey 的 matte satin，还是 Hello Molly / Six Stories / Club L London 的 satin，缎面都在承担：
- 高级感
- 上镜感
- 婚礼场景适配性

### 3. 领型变化是主要差异化手段
竞品并没有大规模依赖复杂印花或重工，而是通过：
- cowl
- one shoulder
- halter
- asymmetric
- strapless
- square neck  
来做款式区分。

### 4. 颜色策略从“基础色”走向“色盘经营”
不是只卖黑、海军蓝、酒红，而是在此基础上扩展：
- Sage / Olive / Moss Green / Eucalyptus
- Powder Blue / Light Blue / Dusty Blue / French Blue
- Lemon / Butter Lemon
- Champagne / Oyster

### 5. 细节更偏“轻礼服化”
scarf、draped、corset、bow、pleated 等细节高频出现，说明竞品在追求：
- 更强的造型感
- 更高的拍照表现
- 更适合社媒传播的视觉记忆点
